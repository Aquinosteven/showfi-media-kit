# ShowFi

![ShowFi](showfi-logo.png)

ShowFi helps people find their way back to a webinar, event, or sales call they’ve already registered for. After booking, they can save a pass with the event details to Apple Wallet or Google Wallet. When it’s time to join, they can reopen the pass on their phone. Teams can add the pass to their existing confirmation flow using GoHighLevel or Make.

[Website](https://www.showfi.io/) · [Interactive attendee demo](https://www.showfi.io/pass-experience) · [Pricing](https://www.showfi.io/pricing)

## How it works

A webinar organizer adds a ShowFi pass to the registration confirmation. An attendee saves it to Wallet. The pass keeps the webinar time and join link together, and the organizer can update event details after registration. Reminder visibility depends on the phone and its settings.
